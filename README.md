# TalkFlow

[TalkFlow](https://talkflow.app) is a private AI interview copilot for macOS and Windows. It provides real-time transcription, concise role-aware answers, live coding guidance, and post-interview debriefs while remaining hidden from screen sharing.

## Highlights

- Works with Zoom, Google Meet, Microsoft Teams, Webex, HackerRank, CoderPad, and LeetCode
- Native support for macOS 13+ and Windows 10/11
- Plans start at $9.99 per week

Learn more and download the app at **[talkflow.app](https://talkflow.app)**.
